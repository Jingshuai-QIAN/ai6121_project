## 路线对比

| | 旧报告方案（manual-projective-sfm） | 最终使用的方案（sift-calibrated-sfm） |
|---|---|---|
| 找对应点 | 每张图手工标注同一组 8 个地标 | SIFT 自动检测与匹配大量特征 |
| 相机内参 | 不要求预先知道 | ~~通过棋盘格标定或可靠设备参数获得~~ 见 4. |
| 几何方法 | Fundamental Matrix \(F\)，射影重建 | Essential Matrix \(E\)，标定重建 |
| 重建结果 | 三维结构存在射影歧义，形状可能变形 | 理想条件下恢复形状，但整体尺度仍未知 |
| 点云规模 | **通常就是标注的那些点** | 可得到更多稀疏三维点 |

### sift-calibrated-sfm

采用 SIFT 自动匹配、增量式 SfM 和共享内参优化，从图像中寻找大量对应点，允许各点只在部分视图中出现，并随着新视图加入持续扩充稀疏点云。

### manual-projective-sfm

输入8个标注的点也只能输出8个点，增加照片也不会自动生成更多点，它甚至都用不到照片本身，只需要坐标。

##### 可能的用途
- 验证几何算法：人工保证对应关系正确，可以单独检查相机估计、三角化和 BA，避免自动匹配错误干扰调试。
- 作为小型基线：展示从二维观测恢复三维地标，以及优化前后的重投影误差。



## 1. 做了什么

- **实现了可独立运行的 CPU 稀疏 SfM。** 从 SIFT 双向匹配、几何验证和多视图 tracks，到增量相机注册、三角化、共享内参 BA，再导出彩色 PLY、相机和质量指标。
- **跑通了两组真实数据。** Double Helix 注册 **49/49** 个视图，得到 **12,609** 个场景点和 **399** 个金属带支持点。Boxes 注册 **25/25** 个视图，得到 **16,746** 个场景点和 **706** 个盒身支持点。
- **完成了同输入 COLMAP 稀疏对照。** COLMAP 在 Boxes 上有更好的盒身覆盖，差距在特征与匹配阶段已经出现。Double Helix 的两套结果都只有断续片段。提高特征上限、扩大配对窗口和位姿引导复核只带来小幅改善。COLMAP 保留为外部诊断基线。
- **整理了三组报告素材。** Boxes、Double Helix 和 COLMAP 对照共 **5.3 MB**，含代表图、图注、指标及自主点云。 [素材目录](/report_reference/results)

## 4. 最后采用的内参方案

最终方案的内参来自**近似初始化，再用多视图 Bundle Adjustment（BA）联合优化**。视频元数据没有提供可用的焦距，因此先按工作图像长边给焦距一个初值。

| 场景 | 工作图像尺寸 | 初始焦距 | 最终估计焦距 |
|---|---:|---:|---:|
| Double Helix | 720 × 1280 | \(0.65 \times 1280 = 832\) px | **619.24 px** |
| Boxes | 1280 × 720 | \(0.90 \times 1280 = 1152\) px | **1187.35 px** |

每段视频的所有帧共享同一套内参。模型设 \(f_x=f_y=f\)，主点固定在图像中心 \(((W-1)/2,(H-1)/2)\)，倾斜和畸变均设为零。先用初始内参恢复种子相机与三维点，再在 BA 中同时调整**共享焦距、相机姿态和三维点**，让投影尽量贴合检测到的 SIFT 像素位置。焦距有上下界和弱先验。我们也单独测试了一个径向畸变参数 \(k_1\)，最终主结果采用零畸变模型。

所以，**832 px 是人为设定的初值，619.24 px 是由 Double Helix 多视图观测联合估计出来的焦距**。报告里应称为「自标定估计」，单位是工作图像像素。[Helix 相机参数](/report_reference/results/helix/cameras.json) · [Boxes 相机参数](/report_reference/results/boxes/cameras.json)
