## 3. 工作包与完成标准

### T00 — 工程基础、接口、合成数据（P0）

依赖：无。负责人：C 协调，A/B 审阅接口。

- 创建 `pyproject.toml`、可安装 `src/sfm`、`python -m sfm` CLI、`configs/default.json` 和版本锁定；验证干净虚拟环境可安装。
- 将架构第 5 节变成 dataclasses/类型定义与结构校验；错误状态使用枚举或固定字符串，禁止靠日志文本判断成功。
- 建立合成 generator：已知 K、至少 5 个相机、有重叠的非共面 3D 点，投影得到可见观测；保留 GT、可控像素噪声、匹配外点与随机种子。默认建议 200 点、噪声 0/0.5/1 px、外点比例 0/0.2。
- 同一 fixture 能给 B 输出对应点，给 C 输出相机与点，给 A 输出模拟匹配边；固定小数据随测试提交。
- 配置加载拒绝未知键、非法阈值和缺失必要项；生成 resolved config。只为尚未实现的功能保留明确 `NotImplementedError`。

验收：CLI help 可用；包安装测试可用；合成投影满足预设相机的正深度/可见性，序列化 round-trip 保留 ID、dtype 与坐标含义。非有限值、错配形状、重复 observation 被拒绝。只需有意义的契约测试，不写逐行复述实现的测试。

### T01 — 数据检查、标定与预处理（P0）

依赖：T00。负责人：A；采集者提供数据。

- 用可用的视频工具检查实际分辨率、时长、帧数与读取情况，保存结果；不存在 ffprobe 时用 OpenCV，不为这一工具阻塞。
- 实现 `prepare`、`calibrate`、`inspect` 所需数据路径、manifest、帧源索引与 contact sheet。先保留可用的 25 帧候选，供人工复核。
- 实现相机标定导入/生成、缩放 K、去畸变与有效区域 mask；无标定数据时工具可以完成，真实标定结果标为缺失。
- `inspect` 可对未标定原图做外观/特征诊断，明确该坐标空间；其特征缓存不可复用于已去畸变图像。
- 产出具体数据采集单：同一镜头与拍摄模式的棋盘图、尺寸/内角点数、视频模式与防抖状态；记录元数据无法证实的字段。

验收：抽帧可追溯回源视频；不同工作分辨率下同一投影的像素映射一致；缺 K 的正式重建报 `missing_calibration`。不覆盖视频，不虚构标定 RMS。尚无真实棋盘图不阻止 T02–T07 的合成与模块开发。

### T02 — SIFT、匹配与可视化（P0）

依赖：T00/T01；几何验证暂接接口。负责人：A。

- 实现 SIFT、稳定 keypoint IDs、L2 KNN、双向 ratio 与 mutual check。
- 实现顺序 window 图对调度、去重和缓存；保留生成图对的原因。
- 输出 keypoints overlay、匹配图、每对统计与匹配图连通性摘要。
- 无特征、描述子不足、全无匹配是正常失败结果，不能使整个工具崩溃。

验收：同一观测不在一对图中匹配多个观测；交换图像时关系与索引变换一致；参数或输入变化触发正确缓存失效。至少一个真实图对有可人工检查的输出，不要求此时完成重建。

学习交付：解释 ratio 0.6/0.75/0.9 在一个真实图对上的数量变化，并人工检查错配，不预设“越多越好”。

### T03 — 自实现几何估计（P0）

依赖：T00。负责人：B。

- 实现 Hartley normalization、8 点零空间求解、E 约束、pixel Sampson error、RANSAC 与内点重估。
- 实现 E 的 4 解分解与 SO(3) 校验；正深度选择通过 T04 接口使用三角化，不复制另一套 DLT 到 geometry.py。
- T04 未完成时可在测试中使用明确命名的 OpenCV oracle，不允许让 oracle 成为主实现。
- 保存迭代数、样本退化数、内点数、误差分布与最终 mask，不能只返回 E。

验收：无噪声良态 fixture 达到架构的误差目标；恰好 8 点专门测试右零空间；带 20% 外点的固定 fixture 有足够正确内点并恢复合理姿态（建议 precision >=0.95、recall >=0.8，阈值与噪声一起锁定）；纯旋转/近共线/不足 8 点被正确拒绝或标记退化。不能要求所有噪声场景都达到无噪声精度。

学习交付：解释 E 与 F 的区别、像素阈值为什么经 K 转换、平移为什么只有方向。

### T04 — 三角化、投影与基础指标（P0）

依赖：T00。负责人：C。

- 实现两视图/多视图 DLT、齐次除法、正深度、视差与重投影过滤，返回每个拒绝点的原因。
- 实现以有效观测为单位的误差向量及 RMSE/median/p90，明确 RMSE 为 `sqrt(mean(||u_pred-u_obs||²))`，不是 x/y 标量样本 RMS。
- 相机中心计算、颜色采样规则、ASCII PLY、无 GUI 的相机/点云 PNG 视图。

验收：已知相机的无噪声点重建正确；点在相机后方、低视差、无穷远、错误匹配会被筛掉；camera-to-world 与 world-to-camera 混用会触发测试失败。导出的 PLY 点数与有效点数一致，BGR 不误当 RGB。

### T05 — Tracks 与两视图初始化（P0）

依赖：T02/T03/T04。负责人：A（tracks）+ B（初始化）。

- 实现带同图冲突检查的 deterministic union-find 与不可变 ID。
- 在 verified pair 图上完成连通分量、候选种子评分与失败输出。
- 种子相机建立唯一世界坐标，注册两个相机和对应有效点；复用 T04 的过滤。
- 输出两视图 checkpoint 供后续模块与 BA 消融使用。

验收：A–B、B–C 匹配能生成三视图 track；故意加入同图不同 keypoint 的边不会非法合并。所有点/track/观测 ID 可双向追溯。真实两视图能输出几何诊断；失败则优先定位数据、内参和视差，不跳过检查。

### T06 — 增量式多视图注册（P0）

依赖：T05。负责人：B（PnP）+ C（调度）。

- 从 tracks 建立唯一 2D–3D 对应；实现 PnP RANSAC、细化与质量门槛。
- C 实现候选排序、注册事务、新点三角化、观测过滤、有限重试与停止条件。
- 状态更新先在候选副本验证，通过后提交；PnP 失败不污染 state。
- 全程保持种子尺度，不使用相邻 pair 的单位平移串接；输出每轮 registration log。

验收：合成 >=5 相机恢复同一坐标系，相似变换对齐后轨迹和点误差受控；一张坏图不会阻止剩余可注册图；断开子图明确上报；重复观测不会造成一对多 PnP。真实多视图目标至少 5 相机，若数据不足则报告阻塞与需要重采的位置。

### T07 — BA 与结果过滤（P0）

依赖：T00/T04 可开始；最终集成依赖 T06。负责人：C。

- 实现 rotation-vector 参数打包/解包、固定第一相机和第二相机一个非零平移分量、点参数、像素残差及 jac_sparsity。
- 写清安全投影与深度惩罚的数值定义和配置；优化中观测集、变量数及残差维度固定。深度罚项单独计量，不混进像素 RMSE。
- `least_squares` 输出完整状态；固定支持集上的目标恶化、非有限结果或深度失效则回退。记录是否触发 max_nfev，不能把仅迭代用尽写成收敛。
- 集成周期性 BA 与最终 BA，保留 pre/post checkpoint；过滤后再优化时保留原支持集统计。

验收：在有噪声/扰动的良态合成例上固定支持集目标下降；第一相机与固定尺度分量严格不变；有效点/位姿有限；重复执行不出现任意尺度漂移；用故障注入验证优化失败可回退。测试不能只断言“SciPy 返回成功”。

学习交付：对比一个带噪示例的 BA 前后点云和残差；解释为什么固定 gauge，以及 Huber cost 与普通 RMSE 的区别。

### T08 — 可复现实验与证据（P0）

依赖：T01–T07。负责人：三人及实验成员。

- 在实际输入与真实标定上跑主配置、BA 消融、采样密度变化；资源/数据不足时先保主结果与 BA 消融，清楚列出未做项目。
- 无 BA/有 BA 从同一状态分支；采样实验使用同一时间范围，保存精确帧列表，避免比较不同内容。
- 输出 architecture 第 8 节所有产物，数据统计可由脚本重算；三幅关键图有人复核：匹配、重投影、相机与点云。
- 重建可包含背景；需提供至少一张能说明雕塑上是否有实际重建点的图。无雕塑点不能仅用背景点云宣称对象已成功恢复。
- 固定输入/seed 的两次运行应在容差内一致；不强求所有第三方数值线程位级一致。报告实际运行时间而非估算。

验收：在独立干净环境按 README 命令能生成同类结果；失败图、未注册图、低质量标定都在报告数据里可见；不删除失败分母。主结果达不到目标时优先重采、改善标定或减少模糊帧，记录调整前后。

### T09 — 报告迁移与提交包（P0）

依赖：T08 有真实数值后填结果；方法章节可提前准备。负责人：全组，报告负责人整合。

- 将 `report/main.tex` 迁移到已实现的 calibrated incremental SfM，具体替换清单见 architecture 第 2 节。
- 在方法中逐项标注自行实现、库调用、参考开源来源；说明不做稠密表面和绝对尺度。
- 实验只引用可追溯的输出，给出配置、输入规模、注册率、点数、误差分布、耗时、BA 消融、失败分析。
- 更新 Generative AI disclosure，至少涵盖本次架构/任务设计；后续代码与报告协助按实际发生情况增加。不得沿用只声明模板与语法校对的旧版本。
- 封面填入真实姓名学号，检查参考文献、公式、图表与文字一致，编译并检查 PDF。缺成员信息时保留明确未完成状态，不替用户猜测。
- 打包源码、锁定依赖、配置与所需输入/获取说明、PDF；确认 NTULearn 的具体截止时刻，由组员执行最终提交。

验收：无未解决 LaTeX 引用、占位结果、旧 8 点主线或虚构数字；封面信息完整；PDF 视觉检查通过；交付包按命令可运行。若需要制作/检查 PDF，执行 agent 应读取适用的 PDF 技能。
